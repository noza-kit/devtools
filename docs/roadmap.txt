[~] pdfcraft(仮): 分割、統合、圧縮、注釈の読み込みを一括で行えるローカルツール。

[~] snapclip: スクリーンショットツール+クリップボード管理ツール: 

[~] slidecraft: HTML → スライド変換: HTMLの構造をパースし、Google SlideやPPTXなどの編集可能なスライド形式に変換するツール。

[~] kanbancli: Markdownファイルで完結するオフラインタスク管理CLI。

[~] notesearch (将来のRAG基盤): Documentsディレクトリ等全体を対象としたベクトル意味検索。適切なファイルフィルタリングとチャンク化を行い、将来的にLLMと繋いでRAGとして拡張できる設計にする。

[~] airnotify: watchdogでファイル受信ディレクトリを監視し、受信した瞬間に通知を飛ばす（既存プロジェクトへの追加）。

[~] gazemouse: 視線と体の動きでマウスを操作する
独立系ユーティリティ

知識管理・タスク管理（新ドメイン）

監視・通知の横展開（方向性A）
[ ] releasewatch: GitHub ReleasesのAtomフィードを監視し、依存しているOSSの新バージョンが出たら通知。

[ ] procwatch: psutil等を用いて特定のプロセスやポートの死活を監視し、停止や切断を検知したら通知。

[ ] subtrans: 動画の字幕ファイル (.srt/.vtt) 専用の翻訳ツール。既存のDeepL翻訳基盤を流用。

[ ] camwatch: OpenCVの背景差分などを利用した簡易的な動体検知ツール。カメラに動きがあれば通知。

[ ] dupwatch: サイズベースで一次選別を行う軽量な重複ファイル検知ツール。指定容量を超えたら通知。

既存プロジェクトの連携・拡張（方向性C）

[ ] wikiwatch: フィード監視で見つけた新着情報を通知するだけでなく、Markdown形式で保存して蓄積する（notesearchの検索対象としてエコシステムに組み込む）。

[ ] deskbriefing: PC状態、ストレージ、メール、フィードなどの情報を収集し、朝1回サマリーとして統合通知する仕組み。

[ ] findtranslate: 検索ツール(devfind)と翻訳ツール(translate-comments)をパイプ処理で繋ぎ、1コマンドで完結させるグルーコード。
