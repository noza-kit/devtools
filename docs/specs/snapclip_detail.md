スクリーンショット＆クリップボード拡張ツール（仮: snapclip）完全仕様書
1. コアコンセプト
ピンポン作業の撲滅: 「コピー（スクショ）して、アプリを切り替えて、ペーストする」という無駄な画面往復を、スタック（FIFO）機能によってゼロにする。

ドキュメント執筆のシームレス化: 画像の保存、リネーム、パスの記述を全自動化し、クリップボードにはMarkdownやLaTeXの構文として格納する。

標準機能との共存: 純粋なプレーンテキスト化など、OS標準（Win+VやCtrl+Shift+V）で足りているものはあえて実装せず、開発者・研究者のペインポイント解決に特化する。

2. 機能一覧・詳細仕様
モジュールA: 高度なキャプチャ機能 (Snap)
スタック（キュー）キャプチャモード:

連続して複数枚のスクリーンショットを撮影した場合、それらを内部のキュー（待ち行列）に蓄積する。

ペースト用ショートカットを押すと、蓄積された画像を「古い順（撮影した順）」に一気にペースト、または1枚ずつ順次ペーストする。

Markdown / LaTeX 構文の自動生成 (Auto-Markup):

スクショを撮影した瞬間、指定したディレクトリ（例: ./images）に自動でファイル（YYYYMMDD_HHMMSS.png等）として保存する。

同時に、クリップボードには画像データではなく、ドキュメント用の構文テキストを格納する。

Markdownモード: ![スクリーンショット](./images/xxx.png)

LaTeXモード: \begin{figure}[htbp] \centering \includegraphics[width=\linewidth]{./images/xxx.png} \caption{} \end{figure}

自動結合スクロールキャプチャ (OpenCV Stitching):

縦に長いドキュメントやコード画面などをキャプチャする際、領域を指定してマウスホイールでスクロールすると、裏側でOpenCVがフレーム間の特徴点を抽出し、ズレのない1枚の縦長画像として自動結合（ステッチング）する。

URL指定フルページキャプチャ:

Webブラウザの拡張機能やスクロールを使わず、CLIにURLを渡すだけでヘッドレスブラウザ（Puppeteer/Playwright等）が起動し、ページ全体の完全な縦長スクリーンショットを生成する。

モジュールB: クリップボード履歴・拡張管理機能 (Clip)
FIFO（先入れ先出し）連続ペースト:

テキストや画像を「A」→「B」→「C」の順で連続コピー（Ctrl+C）した場合、専用のペーストショートカット（例: Win+Shift+V）を押すたびに、「A」→「B」→「C」の順で吐き出していく機能。

複数の別々のテキスト（例: 氏名、メールアドレス、電話番号）をコピーしてから、入力フォームへ移動し、連続でペーストしていく用途に最適化。

CLI / TUI インクリメンタル検索 (History CLI):

ターミナルから snapclip history コマンドを実行すると、過去のクリップボード履歴が fzf のようなターミナルUI（TUI）で表示される。

キーワード検索で絞り込み、Enterを押すとその内容が現在のクリップボードに再セットされる。

3. インターフェース設計（使用例とショートカット）
このツールは「バックグラウンド常駐デーモン（ショートカット待機）」と「CLIコマンド」の2つの顔を持ちます。

デーモンモード（バックグラウンド常駐時の挙動）
Alt + Shift + S: スタック・スクショ撮影（撮るたびにキューに溜まり、画像保存＆Markdownリンク化）

Alt + Shift + V: FIFOペースト（スタックされた画像リンクや、連続コピーしたテキストを古い順に1つずつペースト）

Alt + Shift + C: スクロールキャプチャ開始/終了

CLIモード（ターミナルからの操作）
Bash
# 1. URLから完全な縦長スクリーンショットを撮影
snapclip web "https://github.com/example/repo" -o fullpage.png

# 2. クリップボード履歴をTUIで検索し、選択したものを再セット
snapclip history

# 3. 動作モードの切り替え（保存先ディレクトリと出力構文の変更）
snapclip config --mode latex --img-dir "./tex_figures"
